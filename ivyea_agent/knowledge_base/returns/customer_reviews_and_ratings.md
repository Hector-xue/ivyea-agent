# 商品评论与星级：卖家能做什么、不能做什么

Source basis: Amazon 官方 Customer Reviews 工具与评论政策说明页。政策为账号高风险区，处置前必须核对当前站点后台的最新政策原文。

## 官方确立的事实

- 卖家**不能**修改或删除买家写的评论。能做的是：发现违反社区准则的评论时**举报滥用**，由亚马逊判断是否移除（亚马逊表述：会移除违反其政策的评论）。
- 明确**禁止**的行为：影响买家的评分/反馈/评论；要求买家删除差评或发好评；自己或找人给自家或竞品写评论；以退款、返现、免费商品、折扣等任何形式**换取评论**；用买家账号撰写或修改评论；通过买家卖家消息、私下联系或第三方服务承诺"写完评论给退款"。
- 违反评论政策会**影响账户状况**，不处理可能导致**账号停用**。
- 官方允许的争取评论方式只有这几条：
  - Seller Central 的 **Request a Review** 功能；
  - 把商品报名 **Amazon Vine**；
  - 用 **Customer Reviews 工具**处理客诉——该工具可看近 12 个月的评论、按星级等条件筛选，并联系留下**三星以下**评分的买家，提供全额退款或索取更多信息来解决问题。
- 星级评分与文字评论是两回事：有星级不一定有文字。

## 诊断路径：最近差评变多

1. **先确认是不是真的变多**：用 Customer Reviews 工具按时间和星级筛，对比更早的窗口，而不是凭印象。
2. **归因到具体原因**，逐条读三星以下的评论正文，归类：
   - 商品质量/一致性问题 → 供应链与质检；
   - 收到货与详情页描述不符 → Listing 承接问题（见 `listing.product_detail_page`）；
   - 破损、错发、迟到 → 履约与物流；
   - 竞品恶意 / 违反社区准则 → 举报滥用。
3. **合规处置**：对三星以下评分用 Customer Reviews 工具联系买家、给解决方案（退款或索取信息）。**不得**在沟通里要求对方改评或删评——那是政策红线。
4. 需要更多真实评论时，只走 Request a Review 或 Vine。

## 护栏

- 任何"找服务商刷评/测评返现/索评话术"一律不提供，也不要包装成"合规技巧"——那是账号停用级风险。
- 不要承诺举报滥用一定能删掉评论；能不能移除由亚马逊判定。
- 差评变多先做归因，不要一上来就归到"竞品恶意"；多数情况是质量、描述不符或履约问题。
- 站点与时间不同政策细节可能不同，高风险结论必须先核对当前站点的官方政策页。
