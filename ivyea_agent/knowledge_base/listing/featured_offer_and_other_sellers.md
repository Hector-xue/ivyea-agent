# Featured Offer（原 Buy Box）与同一 Listing 上的其他卖家

Source basis: Amazon 官方 Featured Offer 说明页。判定因素由亚马逊控制且会调整，具体权重从未公开。

## 官方确立的事实

- Featured Offer 出现在商品详情页顶部的 Offer Display 区，带 **Buy Now / Add to Cart** 按钮；同一个区域可以有一个或多个 Featured Offer。
- 一个 Listing 上可以有多个卖家的报价。买家可以通过「Other sellers on Amazon」查看 Featured Offer 之外的其他报价——**跟卖本身不等于违规**，它是这个目录模型的正常形态。
- 亚马逊说明的四类判定因素：
  - **有竞争力的价格**：Featured Offer 的价格通常处于或低于最低替代报价；比较的是**含运费的到手价**。
  - **配送速度**：快速免费配送、以及送达日期确定性更高的报价更容易被选中。
  - **客户体验**：持续提供良好订单体验（发对货、无损坏、保证正品）会提高成为 Featured Offer 的机会。
  - **有货**：断货时报价不可能成为 Featured Offer。
- 亚马逊列出的**失去** Featured Offer 的具体原因：断货、价格过高、**价格过低**（后者是为了防止错误定价）。

## 诊断路径：链接被跟卖 / 丢了 Featured Offer

1. **先分清是哪一类问题**——两条路的处置完全不同：
   - **只是被别的卖家跟卖、报价合法** → 这是竞争问题，走下面第 2 步。
   - **跟卖方涉嫌售假、侵权、盗用品牌** → 这是知识产权问题，走品牌备案与侵权投诉路径（见 `brand.brand_registry`、`brand.transparency`），**不要**当成调价问题处理。
2. 按官方四因素逐项核对**自己这一侧**：到手价（含运费）、配送时效与确定性、库存状态、账户绩效指标。
3. 价格排查要包含「价格过低」这一侧——不只是被人压价才会掉，定价异常低同样会失去资格。
4. 绩效类指标（订单缺陷率、取消率、迟发率）在**账户状况**页查（见 `policies.account_health_overview`）。

## 护栏

- 不要把 Featured Offer 的选中规则说成一个公开的权重公式或分数——亚马逊只公布了因素，从未公布权重。
- 不要把「有人跟卖」直接等同于侵权。没有侵权事实就走侵权投诉，是账号风险。
- 不要建议靠**无限降价**抢 Featured Offer：价格过低同样会失去资格，且直接吃掉毛利。
- 不同站点、不同类目、不同时间的判定可能不同；结论要说明适用范围并建议核对当前站点后台。
