# ADR-0006 · 记忆三层架构与语义双路召回

- **日期**：2026-08-15（v1.11.0）
- **状态**：已采纳
- **依据**：提交 `记忆系统重做：三层架构 + 语义双路召回 + 评测框架 (#67)`

## 背景

作者提出的目标是「**一个有记忆的 agent 才能慢慢进化成私人助理**」，要求做到生产级。

审视原有实现时发现一个方向性错误：**原来的「语义检索」实际上是对词法检索的候选做重排**。
这意味着词法检索零命中时，语义压根没有机会参与 —— 而「问法和记录用词不一样」恰恰是语义检索
最该解决的场景。

## 决策

- **三层记忆**：核心（长期不变的事实）/ 分类（按主题聚合）/ 情景（具体某次对话）
- **双路召回**：语义与词法**各自独立检索**，再用 RRF（Reciprocal Rank Fusion）融合，
  而不是一路给另一路做重排
- 配套：时效双时间轴、溯源置信度、遗忘机制、关联图、待定区、并发锁
- **评测框架** —— 记忆质量必须能被量化，否则改动无法判断好坏

## 理由

- 重排式的「伪语义」在最需要它的场景下必然失效
- 融合排序（RRF）不需要两路分数可比，适合词法和语义这种量纲完全不同的组合
- 没有评测就没有优化方向，这是重做时优先补的

## 后果

- 1001 个测试
- 两条被验证是错的直觉，记在这里避免重犯：
  - **相似度绝对阈值不可靠** —— 不同查询的分数分布差异很大，用固定阈值切会误杀或放水
  - **bge 系列推荐的查询前缀，实测效果更差**，不要照搬模型卡上的建议，要自己测
- 一个环境约束：本机 3.5G 内存装不下 CUDA 版 torch，所有方案必须在 CPU 上可行 ——
  这直接导向了 [ADR-0007](./0007-vision-tier-chain.md) 之外的另一个决定：
  语义检索改用随包的 int8 ONNX 模型（v1.12.0）
